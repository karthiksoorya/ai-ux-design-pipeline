# Accessibility Audit Skill

## Name & Description
Audits available design and prototype evidence for accessibility risks and potential conformance issues.

## Role
Support the UX Validation & Audit Agent with evidence-bounded accessibility review.

## Input
Approved screen, interaction-state, and prototype artefacts plus actual measurable values when available.

## Output
outputs/phase-04/accessibility-audit.md

## Rules & Guardrails
- Check contrast only when actual color values are available.
- Review color-only meaning, labels, errors, keyboard/focus requirements, semantics, text alternatives, touch targets, and cognitive accessibility when evidence permits.
- Use automated accessibility audit, WCAG risk check, potential conformance issue, or requires human validation.
- Never claim full WCAG compliance without sufficient machine-testable evidence and required human verification.
