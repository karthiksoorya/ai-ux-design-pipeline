# Information Architecture Skill

## Name & Description
Defines content organization, hierarchy, labels, and navigation needed by the approved concept when information architecture is applicable.

## Role
Support the Experience Design Agent before screen specification.

## Input
D2-approved selected concept, user flow, project content, and constraints.

## Output
Information-architecture decisions represented in outputs/phase-03/screen-spec.md; when substantial, also outputs/phase-03/information-architecture.md.

## Rules & Guardrails
- Run only when navigation, hierarchy, taxonomy, or content organization is material.
- Record NOT APPLICABLE with rationale when it is unnecessary.
- Do not invent content, labels, or product areas unsupported by the approved concept.
