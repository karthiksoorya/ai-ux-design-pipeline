# Problem Framing Skill

## Name & Description
Transforms approved discovery evidence and business context into concise UX problem statements.

## Role
Support the UX Definition Agent in defining what problem should be solved before solution design begins.

## Instructions
For each problem, capture user/context, observed problem, evidence, impact, related business goal/constraint, confidence, assumptions, contradictions, and validation need.

## Input
Approved Phase 1 outputs plus relevant project requirements.

## Output
outputs/phase-02/problem-definition.md

## Rules & Guardrails
- Keep user evidence separate from business requirements.
- Do not prescribe a solution inside the problem statement unless explicitly labeled as an existing constraint.
