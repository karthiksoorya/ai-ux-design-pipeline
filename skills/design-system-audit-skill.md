# Design System Audit Skill

## Name & Description
Compares the approved design against supplied design-system components, tokens, and patterns.

## Role
Support the UX Validation & Audit Agent in distinguishing confirmed deviations from potential mismatches.

## Input
Approved Phase 3 artefacts and supplied design-system evidence.

## Output
Design-system findings in outputs/phase-04/validation-report.md and outputs/phase-04/validation-issues.md.

## Rules & Guardrails
- If no design system exists, report NOT AVAILABLE.
- Do not invent components, tokens, patterns, or standards.
- Label a confirmed deviation only when both the design and applicable system rule are available.
