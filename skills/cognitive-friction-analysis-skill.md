# Cognitive Friction Analysis Skill

## Name & Description
Assesses potential cognitive burden in tasks, decisions, content, recovery, and interaction sequences.

## Role
Support the UX Validation & Audit Agent with transparent heuristic friction analysis.

## Input
Synthetic task walkthroughs and approved Phase 3 artefacts.

## Output
Cognitive-friction findings in outputs/phase-04/validation-report.md and outputs/phase-04/validation-issues.md.

## Rules & Guardrails
- Any score must be labeled SYNTHETIC / HEURISTIC SCORE.
- Document scoring method, dimensions, evidence basis, and limitations.
- Do not present a score as measured behavior or empirical usability evidence.
