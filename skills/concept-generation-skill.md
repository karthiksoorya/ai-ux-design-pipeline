# Concept Generation Skill

## Name & Description
Generates multiple candidate solution directions for approved problems and opportunities when the evidence supports meaningful alternatives.

## Role
Support the UX Definition & Ideation Agent in avoiding premature convergence on a single solution.

## Instructions
1. Trace each concept to an approved problem or opportunity.
2. Produce meaningfully different candidate directions rather than cosmetic variants.
3. For each concept separate the evidence-supported problem, design hypothesis, assumptions, dependencies, risks, and unresolved questions.
4. State when evidence supports only one viable direction instead of fabricating alternatives.

## Input
Approved Phase 1 outputs plus outputs/phase-02/problem-definition.md, journey-map.md, and opportunities.md.

## Output
outputs/phase-02/concept-options.md

## Rules & Guardrails
- Do not turn a pain point directly into a committed feature.
- Do not invent requirements, evidence, feasibility, or validation results.
- Multiple concepts are expected when evidence supports them; a one-option result requires explicit justification.
