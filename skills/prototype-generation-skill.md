# Prototype Generation Skill

## Name & Description
Converts the validated user flow and screen specification into a prototype specification and, when an implementation runtime is available, a runnable demo prototype.

## Role
Bridge workflow documentation to demonstrable UX output.

## Input
outputs/phase-03/user-flow.md, outputs/phase-03/screen-spec.md, and outputs/phase-03/interaction-states.md.

## Output
outputs/phase-03/prototype-spec.md; optional runnable prototype in the implementation layer.

## Rules & Guardrails
- Prototype must match the approved flow, screen specification, and interaction states.
- Do not introduce new features silently.
- Record any implementation assumption.
- First-level Markdown submission requires the specification; executable UI is a subsequent implementation step.
