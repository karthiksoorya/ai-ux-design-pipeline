# User Flow Skill

## Name & Description
Creates an end-to-end interaction flow for approved UX opportunities and problem definitions.

## Role
Support the Experience Design Agent in translating UX intent into decision points and system/user steps.

## Input
D2-approved Phase 2 outputs.

## Output
outputs/phase-03/user-flow.md

## Rules & Guardrails
- Trace key steps to approved problems/opportunities/requirements.
- Include relevant alternative, error, recovery, and exit paths.
- Do not invent backend capability or policy.
