# Screen Specification Skill

## Name & Description
Defines the screens and interaction states required to realize the approved user flow.

## Role
Support the Experience Design Agent with prototype-ready screen requirements.

## Input
outputs/phase-03/user-flow.md plus approved Phase 2 outputs and relevant project constraints.

## Output
outputs/phase-03/screen-spec.md

## Rules & Guardrails
For each screen include purpose, entry condition, key content, primary action, secondary actions, validation, error/empty/loading/permission states where applicable, and traceability to flow step.
Do not invent unsupported content, business rules, or data.
