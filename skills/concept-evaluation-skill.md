# Concept Evaluation Skill

## Name & Description
Compares candidate concepts using explicit evidence, value, risk, feasibility signals, assumptions, and unresolved questions.

## Role
Support the UX Definition & Ideation Agent in recommending a direction without presenting judgment as validation.

## Instructions
1. Define selection criteria before choosing a concept.
2. Compare all candidate directions against the same criteria.
3. Document the selected direction and alternatives considered.
4. Preserve evidence, risks, assumptions, dependencies, and unresolved questions.

## Input
outputs/phase-02/concept-options.md plus approved problem, journey, opportunity, BRD-risk, and business-context artefacts.

## Output
outputs/phase-02/selected-concept.md

## Rules & Guardrails
- Recommendation is a design decision for D2 review, not proof of usability.
- Do not hide weak evidence or disqualify alternatives using invented constraints.
- A one-concept input fails evaluation unless its lack of alternatives is explicitly justified.
