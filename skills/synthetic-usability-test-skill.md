# Synthetic Usability Test Skill

## Name & Description
Performs simulated task walkthroughs using approved personas and tasks to identify potential usability friction.

## Role
Support the UX Validation & Audit Agent with heuristic—not empirical—usability analysis.

## Input
Approved personas, selected concept, user flow, screen specification, interaction states, and prototype specification.

## Output
Synthetic usability findings in outputs/phase-04/validation-report.md and issues in outputs/phase-04/validation-issues.md.

## Rules & Guardrails
- Label every walkthrough SYNTHETIC / HEURISTIC.
- Never claim participants were observed or that findings are real-user evidence.
- Trace findings to the inspected artefact and simulated task.
- Recommend empirical validation where uncertainty matters.
