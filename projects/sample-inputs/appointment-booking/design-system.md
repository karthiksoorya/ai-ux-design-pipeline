# Supplied Design-System Extract

## Tokens

- Primary text: `#1F2937` on `#FFFFFF`
- Error text: `#B42318` on `#FFFFFF`
- Focus indicator: `2px solid #2563EB`
- Spacing unit: `8px`

## Components

- Primary button: default, hover, focus, disabled, loading
- Text input: label, optional hint, error message, disabled
- Status message: icon, heading, explanation, next action

## Rules

- Status cannot be communicated by color alone.
- Every input has a persistent visible label.
- Focus indicators must remain visible.
- Error messages identify the field and corrective action.
