# Starter Project Brief

## Purpose
Use this folder for one UX project that will be processed by the AI UX Discovery-to-Prototype Pipeline.

## Required starting input
- At least one BRD, product brief, or equivalent requirement source.

## Optional supporting inputs
- User research notes
- Interview notes or transcripts
- Survey summaries
- Support tickets or customer feedback
- Existing product screenshots or flows
- Analytics summaries
- Stakeholder notes
- Existing UX or design documents

## Important evidence rule
A BRD is a business requirement source, not user evidence. The workflow must keep these source types separate.
